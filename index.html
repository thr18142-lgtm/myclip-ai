How it works

  1. Drop your file

    A video, an audio file or an image. The file stays as it is on your device.

  2. Type what you want

    Plain sentences like “cut the first 5 seconds”, “add captions” or “make it 9:16”.

  3. Check the plan, then apply

    Each change appears in the preview first. Apply it or discard it, and undo any change later.
